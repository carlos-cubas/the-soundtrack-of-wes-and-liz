# The Soundtrack of Wes and Liz

A landscape iPhone game based on *Better Than the Movies* by Lynn Painter, built from
**Samira Cubas**'s game design deck. You play Wes Bennett trying to win Liz Buxbaum's
heart through ten mini games (six levels, a rhythm-game boss and three side quests).
Every level you finish adds a song to "The Liz and Wes Playlist".

The game design, story, levels and rewards are Samira's. The novel and its characters
belong to Lynn Painter. Song previews are streamed from Apple Music.

## Play on an iPhone or iPad

Needs **iOS 16 or later** (iPhone 8 and newer, or iPadOS 16 or later), for both the web
app and the native app. The game runs in landscape on both.

### As a web app (no Mac needed)

1. Open the game's GitHub Pages URL in **Safari**.
2. Tap **Share**, then **Add to Home Screen**.
3. Launch it from the home screen and turn the phone or iPad sideways.

After the first launch the whole game is cached, so it plays offline. Only the
30-second song previews need a connection.

### As a native app (Mac with Xcode)

```sh
npm install
npm run ios:sync   # build the web app and copy it into ios/
npm run ios:open   # open the project in Xcode
```

To install on your own iPhone or iPad with a free Apple ID:

1. Plug in the device and pick it as the run destination at the top of Xcode.
2. Select the **App** target, open **Signing & Capabilities**, set **Team** to your
   Personal Team (Xcode > Settings > Accounts > add your Apple ID first). If Xcode says
   the bundle ID is taken, change `com.samiracubas.wesandliz` to something unique.
3. On the device, turn on **Settings > Privacy & Security > Developer Mode** (it restarts).
4. Press **Run**. The first time, open **Settings > General > VPN & Device Management**,
   tap your Apple ID and **Trust** it, then open the app.

Apps signed with a free account expire after 7 days; run it from Xcode again to renew.

Without opening Xcode, once a device has been set up as above:

```sh
DEVICE=iPad npm run ios:device    # build, install and launch (DEVICE: iPhone, iPad, name or UDID)
TEAM=XXXXXXXXXX DEVICE=iPhone npm run ios:device   # sign with another team
```

To try it in the simulator instead:

```sh
npm run ios:sim    # build, launch in the iPhone 17 simulator, save a screenshot
SIM_DEVICE="iPhone 16e" npm run ios:sim
SIM_DEVICE="iPad Pro 13-inch (M5)" START_QUERY="screen=map" ORIENTATION=left npm run ios:sim
```

The screenshot lands in `ios/App/build/sim-screenshot.png`. `START_QUERY` opens one of
the test URLs below and `ORIENTATION` (`right` or `left`) picks the landscape side.

## Develop

```sh
npm install
npm run dev          # Vite dev server on your LAN, open it on the phone too
npm run typecheck    # tsc --noEmit
npm test             # vitest
npm run build        # typecheck + production build into dist/
npm run preview      # serve dist/ (the service worker runs here)
npm run ios:icons    # regenerate every icon size from public/icons/icon-1024.png
```

Handy URLs while developing: `?play=l1` jumps straight into a mini game,
`?play=l1&flow=1` runs its narration, game, rewards and outro, `?screen=map` opens the map.

Pushing to `main` builds the game and publishes `dist/` to GitHub Pages
(`.github/workflows/pages.yml`). Enable it once under **Settings > Pages > Source:
GitHub Actions**.

## Layout

```
src/main.ts          boot, screen routing, service worker registration
src/core/            stage (canvas), input, audio, save, app (screen switching)
src/data/story.ts    all story text, levels, rewards and songs
src/games/<id>/      one folder per mini game
src/screens/         title, map, narration, play host, rewards, playlist, ending
src/ui/              DOM helpers and the HUD
public/              art, fonts, audio, icons, manifest.webmanifest, sw.js
capacitor.config.ts  native app settings (app id, name, web view)
ios/                 Xcode project generated by Capacitor
tools/               art/audio generation, screenshots, build-sw.mjs, ios_*.sh
docs/SPEC.md         build spec
```

The service worker (`public/sw.js`) precaches every built file. Its file list and
version are filled in during `vite build` by `tools/build-sw.mjs`.
